## Introdução

Laravel Passport é uma implementação completa de servidor OAuth 2.0 para Laravel. Ele fornece um sistema de autenticação baseado em tokens para proteger suas APIs.

---

## Premissas

- Versão passport utilizada v13.4.1
  - Como verificar: `composer show laravel/passport` no terminal

---

## Instalação

1. Instale o Passport via Composer:
```bash
composer require laravel/passport
